# OAuth Branding Site Files

These two HTML files are for the Google Cloud OAuth consent screen branding.

## How to use

1. Create a GitHub repo named `yourusername.github.io` (replace `yourusername`)
2. Upload `index.html` and `privacy.html` to that repo
3. Enable GitHub Pages (Settings → Pages → Deploy from branch: main)
4. Verify domain in Google Search Console (add meta tag from step 1)
5. Update OAuth consent screen:
   - Home: `https://yourusername.github.io`
   - Privacy: `https://yourusername.github.io/privacy.html`
   - Authorized domains: `github.io`

## Files

- `index.html` — Home page (replace `your-email@gmail.com`)
- `privacy.html` — Privacy policy page
